# 教員用メモ

各回のファイルは新しいスライドのページ順に対応します。前版の一律の90分進行表とは別に、操作を待つ箇所と例を説明する箇所を示しています。既定の授業時間を新たに変更するものではありません。

初回は導入スライドでアカウントと保存先を整えてから第1回へ進みます。設定に時間がかかる学生には授業側の代替提出手順を案内し、登録や特典審査の完了をAI学習の達成と混同しないでください。第3回のDesktop部分は発展扱いなので、端末にインストールできない学生もブラウザで完了できます。

授業の開始前に、学生用template repository、招待する教員username、学内の登録・提出リンクを用意してください。提出先には授業で利用できるフォームやLMSを使い、実際のリンクと使用アカウントを案内します。
