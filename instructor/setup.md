# 初回準備：教員用進行メモ

学生向けの[37ページの準備スライド](../slides/00_Course_Setup.pptx)と[1つずつ進める手順](../docs/setup_handson_step_by_step.md)に対応します。授業前に[授業に合わせる項目](../docs/instructor_adaptation.md)を確認してください。

## 進める順番

| ページ | 行うこと | 学生が確認する目印 |
|---|---|---|
| 1〜4 | 目標と保存・提出の場所を確認 | 教材を読む場所と自分の保存先の違いが分かる |
| 5〜9 | 授業用アカウント、GitHub、メール、usernameを確認 | 正しいアカウントと自分のusernameを控えた |
| 10〜14 | ひな形から自分のPrivate保存先を作成 | 所有者が自分で、Privateと表示される |
| 15〜20 | 画像を保存・アップロード | 自分のsetupで画像を開ける |
| 21〜25 | 短い利用記録を編集・保存 | 画像名・利用方法・確認したことが読める |
| 26〜27 | 担当教員のアカウントを招待 | 招待中または登録済みの表示がある |
| 28〜32 | 初回登録 | 自分の情報とリポジトリURLを送信し、完了画面を確認した |
| 33〜35 | 次回の提出と困ったときの対応 | commit URLを提出する場面と連絡方法が分かる |
| 36〜37 | 希望者向けの特典・学習目標 | 任意項目を準備完了の条件と区別できる |

## 操作を待つとき

作成済みの学生は同じ保存先で続けます。画像生成が利用できない学生は配布画像を使えます。招待受理や個別コメントを待たせず、学生側の保存・招待・登録が済んだら次へ進めます。

止まった場合は表示中のページ、操作した箇所、エラー文を確認します。パスワードや認証コードを見せさせません。学籍番号・氏名・大学メールは授業の受付先で集め、公開プロフィールや公開ひな形へ書かせません。

途中参加者も同じ準備を行います。過去の課題・締切は担当教員の方針を別に案内します。詳しい説明と出典は各スライドのノートにあります。
