# Teaching the GitHub clinic

Allow approximately 30 minutes. Give account creation and authentication extra help when needed. Keep the published assessment and deadline policy.

Use the [15-step deck](../slides/GitHub_Hands_On_EN.pptx), [student guide](../handouts/github_hands_on.md), and [three short videos](../../videos/github/README.md). Publish named course links for the teaching material, empty template, initial form, and weekly form. Specify your instructor username and the week folder used for practice; keep university-only form URLs out of public material.

| Time | Live demonstration and student action | Pause and check |
|---|---|---|
| 0–3 min | Find each student's stopping point | Keep existing repositories and work |
| 3–10 min | Steps 1–5: sign-in and own Private copy | Own Owner, Private, and folder list |
| 10–18 min | Steps 6–9: edit, Preview, final save, reopen | Saved sentence outside the editor |
| 18–23 min | Step 10: invite the specified instructor | Pending and accepted listed separately |
| 23–30 min | Steps 11–15: history, commit, Browse files, URL, form | Required files and form receipt checked separately |

Demonstrate one action, pause, and let students show the cue on their own screen before continuing. Help those who stopped. Do not grade video viewing or uniform operation speed. Never project student secrets or other students' work.

Distinguish reading the instructor repository from creating a student copy. Star and Follow do not copy or grant access. Preserve existing work when a student used Fork or Public. Missing edit controls or Propose changes calls for an ownership and sign-in check. Preview is not saving. The final Commit changes confirmation must be followed by reopening the file. Pending invitation is sent but not yet accepted. Use the clock and Commits, the latest save message, or the student's own `/commits/main/` address to find history. Copy the full `/commit/` address, not the SHA alone or the `/tree/` Browse files address. Verified is a signature indication, not course receipt or grading.

Record the student's completion cues separately from actual instructor access, roster matching, and batch results. Use the existing checker only in an environment whose authentication, roster, and real access were verified. Do not promise feedback delivery from an unverified deployment. Keep existing late-joining, resubmission, and deadline policies. This clinic supplements setup and Week 03; it adds no separate form or graded week.

## Student review in order

The deck has 18 pages: one cover, action steps 01–15, and two self-check pages. Give students the [ordered self-check sheet](../handouts/github_self_check.md). Have them open each screen for items 01–08 before marking it, and leave uncertain items visible for help. Allow extra time after the 30-minute practice or during follow-up.

Item 03 uses the existing setup guide for the image and short record. Items 07–08 review existing form receipts. If uncertain, check on the instructor side before deciding what to do; do not ask everyone to register or submit again. Keep student cues separate from instructor invitation acceptance, actual access, and roster matching. Add no grading requirement.
