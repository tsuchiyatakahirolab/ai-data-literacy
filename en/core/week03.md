# Week 03: Keeping a learning record with GitHub

[Japanese edition](../../core/week03.md)

## Learning objective

Use GitHub to keep artifacts and change history and to identify the exact version submitted.

## Guiding question

A finished file does not show how it changed. Use GitHub to record what changed and to identify the exact version you submitted.

## Materials

- [`docs/github_onboarding_student.md`](../docs/github_onboarding_student.md)

## In-class activity

1. Review the difference between Git, GitHub, a repository, and a commit.
2. Use the private repository prepared in the opening session. Edit the assigned README and compare the changes. If setup is incomplete, follow the onboarding guide first.
3. Upload the small practice.txt file to week03, link to it from the README, and verify that it opens. Commit the final version and submit its commit URL rather than the repository home page.

## Assignment

Complete the activity above and save the required artifact together with a short AI-use record in your course repository.

## What to record in your README

```markdown
# Week 03: Keeping a learning record with GitHub

## Artifact
Link to or place the artifact produced for this week.

## AI service(s) used
List the service(s). If you do not know the model name, write “unknown.”

## AI capability used
For example: explanation, web research, document reading, image understanding, data analysis, image generation/editing, voice, or multi-step task execution.

## What I delegated to AI
Describe the task given to AI in 2–4 sentences.

## What I checked or revised myself
Describe what you verified and what you changed in 3–5 sentences.

## Remaining issues
Note anything you could not verify or complete.
```

## Submission

Update `week03/README.md`, add any required files to the same folder, commit the changes, and submit the **commit URL** through the course form.

Suggested commit message: `week03-submission`

## Checklist

- [ ] The required artifact is included.
- [ ] I recorded what I delegated to AI.
- [ ] I recorded what I checked or revised myself.
- [ ] I did not include personal, confidential, or non-public information.
- [ ] I submitted a commit URL, not the repository home page.

## Version 1.1 teaching update

Basic account setup now takes place in the opening session so that Weeks 1–2 can also be submitted through GitHub. In Week 3, students edit a README, compare versions, and submit the final commit URL. Browser editing is the core route; GitHub Desktop is an optional extension.

AI assistance is optional for this GitHub practice. If you do not use AI, write “not used” and record the changes and checks you performed yourself.


Initial registration uses the repository URL. Weekly submissions use the final commit URL. Setup images and a short record belong in setup. Late joiners use the same registration form. Read the instructor handout and write in your own week03/README.md.
