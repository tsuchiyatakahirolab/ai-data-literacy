# Week 11: First steps in AI-assisted data analysis

[Japanese edition](../../core/week11.md)

## Learning objective

Use AI to inspect a CSV, aggregate data, create a chart, interpret the result, and state a limitation.

## Guiding question

AI can assist with data analysis without manual coding, but a polished chart can still be wrong. Inspect the data before interpreting it.

## Materials

- [`assets/week11/ai_study_data.csv`](../assets/week11/ai_study_data.csv)

## In-class activity

1. Upload the CSV and inspect row count, columns, ranges, and missing values.
2. Produce one aggregation and one chart.
3. Check the result against the source data, then write a short interpretation and limitation.
