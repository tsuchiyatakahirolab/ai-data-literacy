# Week 10: Reading charts critically

[日本語](../../core/week10.md)

## Learning objective

Inspect axes, scales, units, and aggregation choices and distinguish a chart’s visual impression from what the data show.

## Guiding question

The same data can create different impressions depending on axes and scale. Learn what to inspect before accepting a chart’s message.

## Materials

- [`assets/week10/misleading_chart.png`](../../assets/week10/misleading_chart.png)

## In-class activity

1. Ask AI to explain the provided chart and compare the explanation with your own reading.
2. Check axes, scale, units, time period, denominator, and aggregation method.
3. Explain any misleading feature and propose a clearer description or chart design.
