# Week 03: GitHub terms that are easy to confuse

| Term | Meaning | Use in this course |
|---|---|---|
| username | The account name in a GitHub URL, such as `example-student`. | Initial registration. |
| profile URL | The account’s profile, such as `https://github.com/example-student`. | Helps you identify your username; it is not your submission repository. |
| repository URL | The place where your course files are stored. | Initial registration. |
| commit URL | A URL identifying one recorded change and the files at that point. | Weekly and final submissions. |

A repository home URL does not identify a fixed submission version. Submit the final commit URL for each assignment.
