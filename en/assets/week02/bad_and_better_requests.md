# Week 02: Improve an ambiguous request

## Example 1

Ambiguous: “Write a report.”

Clearer: “Explain the benefits and precautions of using generative AI in class for first-year university students in 600 characters. Give two benefits and two precautions, then end with one sentence about what readers should check themselves.”

## Example 2

Ambiguous: “Summarize this document.”

Clearer: “Using only the attached document, summarize it in three points. Do not guess information that is absent. Write ‘This cannot be confirmed from the document’ where appropriate.”

## Practice

Write one ambiguous request, then revise it so that the purpose, materials, output format, and checks are clear. Character limits mirror the source exercise; an instructor may specify a different length for the language used.
