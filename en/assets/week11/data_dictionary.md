# Data dictionary

This CSV contains fictional educational data, not real student records.

| Variable | Meaning |
|---|---|
| student_group | Fictional group. |
| hours_ai_used | Self-reported hours using AI in one week. |
| confidence_before | Self-rating before the exercise, on a 1–5 scale. |
| confidence_after | Self-rating after the exercise, on a 1–5 scale. |
| source_checked | Whether the person reported checking sources: yes/no. |
| submitted_on_time | Whether the assignment was submitted on time: yes/no. |

There are 60 rows. A zero in hours_ai_used is a valid observation, not a missing value. Association does not establish causation.
