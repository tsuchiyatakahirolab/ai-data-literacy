# GitHub Hands-on Practice

Practice sign-in, your own repository, README saving, instructor invitations, and commit URL submission in a browser. Beginners and students who need to review their setup use the same material.

1. Open the [English practice guide](../handouts/github_hands_on.md) and perform one action at a time. Keep your existing repository.
2. Use the [slides](../slides/GitHub_Hands_On_EN.pptx) or [PDF without notes](../slides/GitHub_Hands_On_EN.pdf) and check each completion cue on your own screen.
3. Pause the [three videos](../../videos/github/README.md) at each action.
4. Finish with items 01–08 in the [student self-check sheet](../handouts/github_self_check.md). Return to incomplete steps.

The deck and PDF have 18 pages: one cover, 15 action steps, and two self-check pages. Action numbers are not page numbers. PDFs are rendered images; copy text from the guide or PPTX. Download MP4 files for playback in a standard video player.

[Download materials, videos, and empty templates](https://github.com/tsuchiyatakahirolab/ai-data-literacy/raw/refs/heads/main/downloads/GitHub_Hands_On.zip) / [日本語](../../github/README.md)

Instructors: use the [teaching plan](../docs/github_clinic.md). Specify your course template, instructor username, existing initial and weekly forms, and practice week. Use the existing setup guide for course-specific preparation. Keep current assessment and deadline policies. Preserve student work; no new confirmation submission is required.
