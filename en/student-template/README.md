# AI and Data Literacy: my learning record

Use **Use this template** to create your own **Private** `ai-learning` repository. Keep the same repository if you have already created it or join later.

Follow the course’s setup guide: upload one image to `setup`, write the three fields in `setup/README.md`, invite the instructor account specified for your course, and submit your **repository URL** through the existing initial registration form.

Each week, read the English hands-on sheet, save your artifact and short AI-use record in the corresponding `weekXX` folder, and save with **Commit changes**. Open the last commit after all required files are saved, then submit its **commit URL** through the weekly form. Use `final` for the final project. Browser editing needs no separate push.

Student ID, name, and university email belong in the course registration form rather than this README or your public profile. Do not save passwords, secret keys, confidential material, or full AI chats. The instructor provides course-specific accounts, forms, deadlines and feedback. Independent self-study readers can omit university registration and instructor invitation.
