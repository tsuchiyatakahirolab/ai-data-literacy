# GitHub Desktop guide

GitHub Desktopを使うと、コマンドラインを使わずに repository の clone、commit、push、pull、差分確認ができます。

## 最低限の流れ

1. GitHub Desktopをインストールする。
2. GitHubアカウントでログインする。
3. 授業用 repository を clone する。
4. ファイルを編集する。
5. GitHub Desktopで変更差分を確認する。
6. commit message を書いて commit する。
7. Push origin を押す。
8. GitHubのWeb画面でcommitを開き、commit URLを提出する。

## 困ったとき

- 変更が見えない場合は、保存できているか確認する。
- Pushできない場合は、ログイン中のGitHubアカウントを確認する。
- 分からない場合は、AIに「GitHub Desktopでcommit URLを取得する手順を教えて」と聞いてよい。
