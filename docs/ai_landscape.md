# AIの見取り図

学生に最初に伝えるべきことは、AIはチャットだけではないという点です。生成AIは、質問に答えるだけでなく、読む、見る、調べる、分析する、作る、複数手順の仕事を進める道具として使われています。

## できることによる分類

| 分類 | できること | 学生向けの例 |
|---|---|---|
| 対話 | 質問、説明、相談、文章作成 | 分からない概念を説明してもらう。 |
| 調査 | Web検索、複数資料の比較 | 出典付きで最近の情報を調べる。 |
| 資料読解 | PDF、Word、画像、表の読み取り | 配布資料を3点で説明してもらう。 |
| データ分析 | CSV、Excel、集計、グラフ | アンケート結果を集計する。 |
| 生成 | 文章、画像、音声、動画の作成 | 告知文やポスター案を作る。 |
| 学習支援 | 説明、小テスト、誤答分析 | 試験範囲を自分用に説明してもらう。 |
| 複数手順 | 計画、調査、比較、修正 | 旅行計画や発表準備を段階的に進める。 |

## できることと正しいことは違う

AIが自然な文章を出しても、根拠が正しいとは限りません。学生は、AIの出力について、発行主体、日付、数字、根拠の範囲、自分が確認した点を必ず意識します。

## 年度更新の考え方

製品名、料金、回数制限、画面の場所は変わります。したがって、授業本体では分類と確認方法を教え、具体的な操作は `tool-guides/` と `current/` に分けます。
