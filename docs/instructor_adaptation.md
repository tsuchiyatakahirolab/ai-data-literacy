# 自分の大学・授業で使う教員の方へ

この教材は、生成AIを初めて使う大学生のための14回と最終課題の演習教材です。必要な回だけでも使えます。まず[スライド一覧](../slides/README.md)と[演習シート](../handouts/week01.md)を開き、授業の時間に合わせて進め方を決めてください。

## 授業の前に決める項目

| 項目 | 教員が用意するもの | 教材の変更箇所 |
|---|---|---|
| 授業ページ | 学生が開くLMSや授業サイト | 初回準備の5ページと補助手順 |
| 使用アカウント | 授業ページや提出先へ入るアカウント、利用できるAI | 初回準備の3・5〜8ページ |
| 学生用ひな形 | setup、week01〜week14、finalを持つ空の保存先 | 初回準備の10〜13ページと授業ページのリンク |
| 招待する教員 | 担当教員本人のGitHub username | 初回準備の27ページのusername欄と配布手順書 |
| 学籍番号 | 自大学で指定された入力形式 | 初回準備の29ページと登録案内 |
| 提出先 | 初回登録、各回、最終課題の受付先 | 授業ページと初回準備の30・33ページ |
| 確認結果の連絡 | 授業ページ・メールなど、学生が確認する場所 | 初回準備の31ページと配布手順書 |
| 締切と評価 | 授業ごとの締切と評価基準 | 授業ページと[評価基準](assessment_rubric.md) |

スライドの`tsuchiyatakahirolab`は教材作成者のアカウントを使った例です。学生に招待させるusernameは担当教員のものに差し替えます。`2026GT0001`も入力形式の例です。大学ごとの学籍番号の桁数・文字種を案内してください。

## 学生用ひな形を用意する

[公開の学生用ひな形](https://github.com/tsuchiyatakahirolab/ai-data-literacy-student-template)と、教材一式の`student-template/`を使えます。授業用に編集する場合は、空のひな形を自分の管理するリポジトリへ置き、学生へそのURLを案内します。教材全体を学生の提出先へコピーする必要はありません。

学生はログイン後、Use this template → Create a new repositoryで自分の`ai-learning`をPrivateとして作ります。作成済みの学生には、同じ保存先を続けて使ってもらいます。実際の学生の学籍番号・氏名・メール・提出物は公開ひな形へ入れません。

## 提出と確認の方法を案内する

初回は画像1枚と短い利用記録を`setup/`へ保存し、担当教員を招待して自分のリポジトリURLを登録します。毎回は必要な成果物とAI利用記録を保存した後、最後のcommit URLを提出します。AIとの会話全文や有料AIの利用は必要ありません。

受付先には授業で利用できるフォームやLMSを使えます。既に使っている受付先がある場合はその設定を確認し、学生に実際のURL・入力項目・使用アカウントを案内します。登録情報と閲覧権限、画像、利用記録の確認方法は[登録と成果物の確認](instructor_setup_check.md)を参照してください。

途中から参加する学生にも同じ準備資料を案内します。過去の課題や締切の扱いは別に伝えてください。点検結果や通知の時期も授業で決め、学生が確認する場所を示します。

## 配布する資料を選ぶ

教員の準備と編集にはノート付きPPTX、学生の閲覧にはノートなしPDFを使います。依頼文のコピーや記録の記入には演習シートを使います。英語の教材本文と導入案内は`en/`にあります。PPTXは日本語です。

大学アカウントや提出を伴わない利用は[独習の案内](self_study.md)に沿って進められます。
