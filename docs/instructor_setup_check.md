# 登録と成果物を確認する

担当教員は授業で決めた方法で、初回登録の情報と学生のPrivateリポジトリを確認します。手動で確認する場合も、授業用の点検システムを使う場合も、次の項目を確かめます。

1. 学籍番号・メール・GitHub username・登録先URLが同じ学生の情報として対応している。
2. 登録先の所有者が申告されたusernameと一致し、教員が招待を受理して閲覧できる。
3. 保存先がPrivateで、画像を実際に開ける。
4. setup/README.mdに画像名・利用方法・自分が確認したことが書かれている。
5. 確認結果と必要な修正を、授業で案内した方法で学生へ伝えられる。

登録内容、確認結果、過去の記録は履歴を残して管理します。途中参加、登録の修正、名簿の追加にも同じ確認方法を使い、招待受理済みの学生へ再招待を求めたり、同じ結果を重複通知したりしないようにします。

名簿・登録情報・確認結果は教員の非公開領域で管理します。閲覧権限とファイルを確認できたことは、本人性や自作性の保証ではありません。成績は授業の評価基準に従って判断します。
