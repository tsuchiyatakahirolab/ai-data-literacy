# 授業方針

この授業は、AIの用語を暗記する授業ではない。学生は毎回の演習でAIを使い、成果物、AI利用記録、確認・修正の説明を提出する。評価の中心は、AIを使ったかどうかではなく、AIの出力をどのように確認し、自分の成果物として完成させたかに置く。

AIの利用は原則として認める。ただし、課題の趣旨に反する丸投げ、出典の未確認、他者の個人情報の入力、成果物の責任放棄は認めない。学生は、どのAIを何に使ったか、自分が何を確認したかを短く記録する。

この授業ではGitHubを使う。GitHubは、変更履歴を残すための道具であり、提出管理のための道具でもある。学生は毎回の成果物を自分の repository に置き、commit URL を提出する。
