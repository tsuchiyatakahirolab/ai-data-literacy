# 教員用運用ガイド

## 授業前に行うこと

1. 公開教材 repository を用意する。
2. 学生用 template repository を別に用意する。
3. Google Forms / Master Dashboard 生成スクリプトを実行する。
4. 初回登録 Form、週次提出 Form、最終課題 Form のURLを確認する。
5. Week 01-14 の prefilled URL をLMSに配置する。
6. 大学アカウント以外では Form を開けないことを確認する。

## 第1回で行うこと

第1回は、AIの見取り図とGitHub初期設定に重点を置く。演習そのものを急がず、大学アカウント、GitHubアカウント、学籍番号形式、repository、commit URL の確認を授業内で終える。

## 毎回の提出管理

学生は成果物を自分の repository に置き、commit URL を提出する。Formで収集するのは提出時刻、学生メール、Week番号、commit URL、使用AI、確認・修正した点である。AIとの会話共有リンクは必須にしない。

## トラブル対応

- Formに入れない学生は、Googleアカウントが大学アカウントか確認する。
- 学籍番号が通らない場合は、半角数字、桁数、先頭の20を確認する。
- commit URLが分からない場合は、repositoryの Commits 画面を開かせる。
- GitHubが難しい学生には、最初の数回だけWeb UIで編集、commitさせる。
- 高度なGit操作は扱わない。branch、pull request、conflict は紹介程度にする。

## 成績処理

Master Dashboard を使い、未提出、重複提出、commit URL形式の誤り、登録 repository 以外の URL を確認する。最終評価では、成果物、確認・修正、AI利用記録、GitHub提出を分けて見る。
