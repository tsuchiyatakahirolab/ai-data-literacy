# 教員用運用ガイド

まず[授業に合わせる項目](instructor_adaptation.md)を確認し、学生が開く授業ページに必要なリンクをまとめます。

## 授業前の準備

1. 使う教材と回ごとの演習シートを選びます。
2. 空の学生用ひな形、教員のGitHub username、提出先を用意します。
3. 授業ページへ初回準備、各回の教材、初回登録・毎回・最終課題の受付先を載せます。
4. 使用アカウントと学籍番号の入力形式を案内します。
5. 学生と同じ条件でリンクが開けるか、提出先の入力と確認結果の表示を確かめます。

既に稼働している提出先は設定を確認して使います。個人情報や受付先の学内リンクは公開教材へ書かず、授業ページで案内します。

## 初回の進め方

[初回準備の進行メモ](../instructor/setup.md)と[学生向け手順](setup_handson_step_by_step.md)を開きます。学生がAIを使えること、GitHubのusername、自分のPrivate保存先、画像と利用記録、教員への招待、初回登録を確認します。作成済みの学生には再作成を求めません。

## 毎回の提出管理

学生は各回の成果物と短いAI利用記録を保存した後、最後のcommit URLを提出します。提出先には学生メール、回、commit URL、使用AI、確認・修正したことなど授業で必要な情報を集めます。AI会話の全文は必須にしません。

## 困ったときの案内

- 授業ページや受付先が開けない場合は、指定されたアカウントか確認します。
- 学籍番号が通らない場合は、大学の入力形式とフォームの案内を確認します。
- commit URLが分からない場合は、リポジトリの履歴から最後のcommitを開きます。
- 画像や利用記録の修正は同じ保存先で行います。登録情報を修正する場合は授業で決めた方法を案内します。
- パスワードや認証コードは見せさせません。

## 確認と評価

[登録と成果物の確認](instructor_setup_check.md)で、登録情報・閲覧権限・画像・短い記録を確かめます。確認待ちと未完了を区別し、結果の受け取り方を学生へ伝えます。途中参加者にも同じ準備資料を案内し、過去の課題・締切は個別の授業方針に従います。

評価は[評価基準](assessment_rubric.md)を参考に、授業で公表した配点と条件を使います。成果物、根拠確認と修正、AI利用記録、提出を分けて見ます。
