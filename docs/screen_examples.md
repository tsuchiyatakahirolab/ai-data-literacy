# 画面例の読み方

初回準備には、公開の学生用ひな形、GitHub公式文書の操作画面、操作箇所を示す模式図を掲載しています。模式図は画面の位置関係を説明するためのものです。

画面に出る所有者・リポジトリ名は例です。学生は授業で指定されたひな形から、自分のPrivateリポジトリを作って操作します。画面の表示やボタンの位置が違う場合は、現在開いている画面と担当教員の案内を確かめます。

画面画像の出典と利用条件は[操作画面の出典](../assets/setup/screens/ATTRIBUTION.md)、各スライドのノート、[参考資料](slide_references.md)にあります。
