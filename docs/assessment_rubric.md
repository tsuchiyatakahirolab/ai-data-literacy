# 評価ルーブリック

## 標準配点

| 観点 | 配点 | 評価内容 |
|---|---:|---|
| 成果物 | 50% | 課題の要求を満たし、読者が理解できる形にまとめている。 |
| 確認・修正 | 25% | AI出力を確認し、誤り、根拠不足、表現の問題を必要に応じて直している。 |
| AI利用記録 | 15% | 何をAIに任せ、何を自分で行ったかを具体的に説明している。 |
| GitHub提出 | 10% | 指定されたフォルダに成果物を置き、commit URLを期限内に提出している。 |

## 評価しないこと

次の点は、原則として点数化しない。

- 特定AIサービスの利用有無。
- 有料版AIの利用有無。
- 長いプロンプトを書いたかどうか。
- AIとの会話をすべて保存したかどうか。
- 用語を暗記しているかどうか。

## 不十分な提出の例

- AIの出力をそのまま貼り付けただけで、確認した点が書かれていない。
- 出典が必要な課題で、出典リンクや確認内容がない。
- 成果物はあるが、commit URLではなく repository URL だけを提出している。
- 個人情報や非公開情報を含むファイルを repository に置いている。
