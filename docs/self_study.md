# 学外から独習する方へ

この公開教材は、大学への登録や授業用フォームへの回答をせずに利用できます。利用できるAIを1つ用意し、各回の教材本文と演習シートを開いてください。大学アカウントのGeminiや、有料プランへの契約は必要ありません。

## 始める順番

1. [第1回の演習シート](../handouts/week01.md)で、説明・書き換え・計画を試します。
2. 各回の[教材本文](../README.md)から必要な資料を保存します。配布データは架空であることを保って利用してください。
3. 成果物と、自分で確認したことを短く記録します。GitHubを練習する場合は自分のPrivateリポジトリを使い、まずAIだけ試す場合はローカルのフォルダでも構いません。
4. GitHubの練習は[第3回](../handouts/week03.md)へ進みます。授業用フォームや教員アカウントの招待は、独習では不要です。

## 授業の履修者として利用する場合

大学アカウント、学籍番号の登録、教員の閲覧権限、commit URLの提出は、授業ページの案内に従ってください。独習用の省略手順を、授業の提出免除として使うことはできません。

## 再利用する教員の方へ

学生用ひな形と提出方法を自分の授業向けに用意し、本文の大学アカウント指定と学籍番号例を置き換えてください。教材本文はCC BY 4.0、生成コードはMIT、Lucideアイコンは同梱のISC／MIT条件に従います。実在の学生情報を公開リポジトリへ追加しないでください。

授業へ取り入れる場合は[授業に合わせる項目](instructor_adaptation.md)を参照してください。
