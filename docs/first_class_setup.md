# 初回も途中参加も、同じ準備をする

第2回以降から参加する人も、[画像保存と初回登録の手順](github_onboarding_student.md)を順に進めます。作成済みなら自分のPrivate保存先で続けます。学内の初回登録フォームを再利用し、Week 00のフォームは作りません。

画像生成の利用可否、画像品質、有料プラン、学生特典の審査は設定完了の条件にしません。教員の個別コメントを待たず、保存・招待・初回登録を終えたら点検結果を待ちます。通知の受け取り方は授業ページの案内に従ってください。

過去の課題や締切の扱いは教員の既存方針を確認してください。未登録は欠席・未履修・不合格の自動判定ではありません。
