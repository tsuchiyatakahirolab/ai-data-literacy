# プライバシーと公開範囲

この教材は公開できますが、学生の提出物は原則として非公開にします。学生用 repository は private で作成し、教員を collaborator として追加します。学生が自分の成果物を公開したい場合でも、公開は成績要件にしません。

公開してはいけないものは、実学生の個人情報、学籍番号、メールアドレス、成績、未公開資料、AIとの会話に含まれる個人情報です。授業で使うサンプルデータは、架空データまたは公開可能なデータだけにします。

公開教材 repository には、教材、架空データ、手順書、評価方針だけを置きます。学生の個人情報、授業用の受付先、非公開の管理表、学生のPrivate保存先のリンクは授業の管理領域で扱います。
