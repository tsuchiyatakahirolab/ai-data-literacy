# 用語集

| 用語 | 説明 |
|---|---|
| AI | 人間の作業を補助する情報処理技術の総称。この授業では主に生成AIを扱う。 |
| 生成AI | 文章、画像、コード、音声などを生成できるAI。 |
| プロンプト | AIに送る依頼文や入力。長い定型文を暗記する必要はない。 |
| hallucination | AIが根拠のない内容を自然な文章として出すこと。 |
| grounding | AIの回答を資料、出典、データに結び付けて確認すること。 |
| Git | ファイルの変更履歴を管理する仕組み。 |
| GitHub | Git repository をWeb上で保存、共有、確認するサービス。 |
| repository | ファイルと変更履歴をまとめて保存する場所。 |
| commit | 変更内容を一つの記録として保存すること。 |
| commit URL | 提出時点の変更を示すURL。repository URLとは違う。 |
| CSV | 表データをカンマ区切りで保存する形式。 |
| Markdown | 見出し、箇条書き、リンクなどを簡単に書けるテキスト形式。 |
