# 配布パックの使い方

`slides/` に現行16本のPPTXと、同じ16本のノートなしPDF、全250ページをまとめたPDFがあります。

- 編集・投影：PPTXを開きます。教員用ノートは元のままです。
- 学生への配布：各回のPDFを渡します。スライド本文のみを収録しています。
- 全体を読む：`slides/AI_Data_Literacy_All_Slides.pdf` を開きます。回ごと・ページごとのしおりを使えます。
- 演習：`handouts/` のシートと `assets/` のサンプルを使います。
- GitHubで初回準備：`docs/setup_handson_step_by_step.md` を順に進めます。
- 空の学生用ひな形：ZIP内の `student-template/` に入っています。ブラウザでの作成には教材本文の公開テンプレートへのリンクを使ってください。

PDFには教員用ノート、コメント、添付ファイルを含めません。PDFはメイリオの表示を保持したスライド画像による閲覧版です。本文の検索・コピー・編集にはPPTXを使ってください。

教材の利用条件は `LICENSE.md`、コードは `LICENSE-CODE.md`、著者情報は `CITATION.cff` にあります。個人ロゴの扱いは `LICENSE.md` の著者表示素材の説明に従ってください。

旧導入v1.3のファイルは公開URLを保つためにリポジトリに残しています。一括ZIPは現行v1.4のみを収録します。実名簿、個別のフォーム設定、認証情報、学生提出物、教員用の運用ログは同梱しません。
