# 教材一式の使い方

`slides/`には初回準備・全14回・最終課題の計16本のPPTXと、同じ16本のPDF、全250ページをまとめたPDFがあります。

- 授業の準備・編集・投影：PPTXを開きます。ノートには授業の進め方と出典があります。
- 学生への配布：各回のPDFを使います。スライド本文のみを収録しています。
- 全体の閲覧：`slides/AI_Data_Literacy_All_Slides.pdf`を開きます。回とページのしおりがあります。
- 演習：`handouts/`のシートと`assets/`のサンプルを使います。
- 自分の授業への導入：[教員向けの準備](instructor_adaptation.md)に沿って授業ページを用意します。
- 独習：[自習の案内](self_study.md)から始めます。授業の登録や教員の招待は不要です。

PDFはノート・コメント・添付を含まない閲覧版です。メイリオによる表示をスライド画像で保持しているため、本文の検索・コピー・編集にはPPTXを使ってください。PPTXにはフォントファイルを同梱していません。
