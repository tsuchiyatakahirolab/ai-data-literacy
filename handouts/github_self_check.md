# GitHub操作補習：学生用の自己確認

教材を読んだ後、自分の画面で01から08まで順に確かめます。**画面を開き、確認できた項目だけにチェック**します。読むだけ、動画を見るだけでは確認になりません。既存の保存先と提出を使い、作り直しません。

[実習手順](github_hands_on.md)／[表紙付きPDF](../slides/GitHub_Hands_On_JA.pdf)／[動画](../videos/github/README.md)

PDFは表紙1枚＋操作15枚＋自己確認2枚の全18ページです。操作番号01〜15はページ番号ではありません。自分の大学の授業ページ、招待する教員のusername、練習する回を確認してから始めます。

各項目は「確認できた」か「未確認・手順不明」のどちらか一つを選びます。

紙や手元のコピーに印を付けるか、教員に自分の画面を示して確認します。公開教材そのものを編集する必要はありません。

## 01  ログインとusername

- **開く場所と操作:** Profileを開き、URLのusernameを読む。
- **できた目印:** 自分のusernameを説明できる。
- **戻る手順:** [手順A1](github_hands_on.md#a1-githubのアカウントに入る)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

## 02  自分のPrivate保存先

- **開く場所と操作:** 自分のai-learningのCodeを開く。
- **できた目印:** Ownerが自分、Private、フォルダあり。
- **戻る手順:** [手順A2・A3](github_hands_on.md#a2-ひな形を自分用にコピーする)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

フォルダがない、Ownerが違う、Publicだった場合は既存の作業を残して教員へ相談します。無断で削除・再作成しません。

## 03  初回の画像と短い記録

- **開く場所と操作:** setupの画像とREADME.mdをそれぞれ開く。
- **できた目印:** 画像が開き、自分の記録が読める。
- **戻る手順:** [初回準備](../docs/setup_handson_step_by_step.md)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

画像のファイルを実際に開き、setup/README.mdの短い利用記録も別に読みます。画像の品質や有料プランは確認条件ではありません。

## 04  教員への招待

- **開く場所と操作:** Settings → Collaboratorsで指定教員を確認。
- **できた目印:** 招待中か受理済みか説明できる。
- **戻る手順:** [手順C1](github_hands_on.md#c1-教員が読めるように招待する)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

招待中は学生が送信した状態です。教員の閲覧は受理後に別途確認します。受理済みなら再招待しません。

## 05  READMEの保存

- **開く場所と操作:** 今週のREADME.mdを開き直し、自分の追記を読む。
- **できた目印:** 編集欄の外に文章が残っている。
- **戻る手順:** [手順B1〜B3](github_hands_on.md#b1-書くファイルを開く)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

まだ保存を練習していない場合は、課題の見出し・文章を残し、実際に行った確認を1行追記して保存・開き直しまで行います。

## 06  提出する版の内容

- **開く場所と操作:** 最新commit → Browse filesで今週の全ファイルを開く。
- **できた目印:** 必要なファイルが全部ある。
- **戻る手順:** [手順C2〜C4](github_hands_on.md#c2-commit履歴の入口を見つける)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

不足があれば保存し直し、その後の最新commitを使います。Browse filesで確認したら、URLをコピーする前に/commit/のページへ戻ります。

## 07  初回登録の送信

- **開く場所と操作:** 自分のリポジトリURLと初回登録の受付を確認。
- **できた目印:** 送信完了を確認できる。不明なら教員へ相談 → 手順C1
- **戻る手順:** [手順C1の初回登録](github_hands_on.md#c1-教員が読めるように招待する)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

すでに送信した人は受付を確認します。完了画面を閉じた場合は、受付メールや授業ページに用意された回答確認を確認し、それもなければ教員へ相談します。確認できないことだけを理由に重複送信しません。未送信の場合は既存フォームを使い、送信完了まで確認します。

- **開く場所と操作:** /commit/のURL全体と週次フォームの受付を確認。
- **できた目印:** 指定回の送信完了を確認できる。
- **戻る手順:** [手順C4・C5](github_hands_on.md#c4-browse-filesで内容を確認してurlをコピーする)
- [ ] 自分の画面で確認できた。
- [ ] 未確認・手順が分からないので、番号を伝えて相談する。

すでに送信した人は受付を確認します。完了画面を閉じた場合は、受付メールや授業ページに用意された回答確認を確認し、それもなければ教員へ相談します。確認できないことだけを理由に重複送信しません。未送信の場合は既存フォームを使い、送信完了まで確認します。

## できない項目があったら

「自己確認06で止まった。Commitsが見つからない」のように、番号と画面に出た文を伝えます。ログインできない場合は先の項目を完了扱いにせず、まず01を相談します。パスワード・認証コードは見せません。このチェックシートは自分の操作確認で、成績や教員の点検結果ではありません。提出物を公開したり、別の確認フォームを送ったりする必要はありません。独習者は授業固有の03・04・07・08を対象外とし、授業で使う人は教員の指示に従います。
