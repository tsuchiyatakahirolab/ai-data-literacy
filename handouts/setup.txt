# 最初の準備

対応スライド：導入 v1.1

## この回で行うこと

大学アカウント・AI・非公開GitHubの準備を終える。

## 使用する資料

- [github_onboarding_student.md](../docs/github_onboarding_student.md)

## スライドを見ながら進める

### 2. 準備するものは、この3つ

- パソコン：ブラウザを開く。充電器も用意する。
- 大学アカウント：授業ページと提出フォームに使う。
- 利用できるAI：大学のGeminiを基本に、他のAIでもよい。

有料契約は不要。ログインできないときは教員に知らせる。

### 3. GoogleとGitHubは別のアカウント

**大学Google**：授業ページ・フォームを開く。 私用Gmailに切り替わって いないか確認する。

**GitHub**：成果物と変更履歴を置く。 既存のアカウントがあれば そのまま利用できる。

### 4. まず、大学アカウントを確認する

1. 授業ページを開く。 右上のプロフィールから、ログイン中のアカウントを見る。
2. 大学のメールアドレスを選ぶ。 私用アカウントではフォームに入れない。
3. 授業ページをもう一度開く。 アクセスできなければ、画面を教員に見せる。

私用アカウントのまま「アクセスをリクエスト」は送らない。

### 5. GitHubに登録する

1. 授業ページの登録リンクを開く。
2. 画面の案内に沿って入力する。
3. 確認メールを開く。

画面に出てくる名前：Email：大学メールを入力 ／ Username：自分で決めた名前 ／ メールを開いて確認を完了

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

本名・学籍番号をusernameに入れる必要はない。

### 6. 既存アカウントには大学メールを追加する

1. GitHubのSettingsを開く。 右上のプロフィールから設定に進む。
2. Emailsで大学メールを追加する。 届いたメールから確認を完了する。
3. メールを非公開にする。 Keep my email addresses privateを確認する。

普段使うメールを大学メールへ変更する必要はない。

### 7. 登録フォームに書く番号を確認する

**正しい例**：2026GT0001 西暦4桁＋英大文字2字 ＋数字4桁

**受け付けない例**：26GT0001：年を省略 2026gt0001：小文字 ２０２６ＧＴ０００１：全角

学籍番号はフォームだけに入力する。公開プロフィールには書かない。

### 8. 自分のusernameを確認する

1. 右上からYour profileを開く。
2. URLの最後の
名前を確認する。
3. 登録フォームへその名前を書く。

画面に出てくる名前：github.com/example-student ／ username：example-student ／ 表示名とは別の名前

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

この画面は例。example-studentは自分の名前に置き換える。

### 9. 授業用のひな形を開く

1. 授業ページのひな形リンクを開く。
2. Use this templateを選ぶ。
3. Create a new repositoryへ進む。

画面に出てくる名前：Use this template ／ Create a new repository ／ Owner：自分のアカウント

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

### 10. 非公開の保存場所を作る

1. ai-learningという
名前にする。
2. Privateを選ぶ。
3. Create repositoryを押す。

画面に出てくる名前：Name：ai-learning ／ Visibility：Private ／ Create repository

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

リポジトリは、ファイルと変更履歴をまとめて置く場所。

### 11. 教員が見られるようにする

1. 自分のリポジトリのSettingsを開く。 Collaboratorsなどのアクセス管理を開く。
2. 指定された教員アカウントを招待する。 ユーザー名は授業ページで確認する。
3. 教員が招待を受けたか確認する。 非公開のままで提出する。

URLを送るだけでは、教員に閲覧権限は付かない。

### 12. READMEに学習目標を書く

1. README.mdを開く。
2. 鉛筆ボタンで
編集する。
3. 自分の目標を2行書く。

画面に出てくる名前：# この授業で試したいこと ／ 資料をAIに読ませてみたい。 ／ 自分で確かめる方法を知りたい。

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

名前や学籍番号ではなく、学習目標を書こう。

### 13. 変更をcommitする

1. Previewを開いて、
表示を確かめる。
2. Commit changesで
保存する。
3. 変更内容を書き、
確定する。

画面に出てくる名前：メッセージ：学習目標を追加 ／ この変更をmainへ保存 ／ Commit changes

操作図は模式図です。画面上の位置が異なっても、操作名と目的を確認してください。

commitは、変更を履歴として確定する操作。

### 14. 登録フォームに初回情報を送る

1. 大学アカウントでフォームを開く。 自動取得されるメールアドレスを確認する。
2. 学籍番号とGitHub情報を入力する。 学籍番号は2026GT0001の形式で書く。
3. 送信完了の画面を確認する。 リポジトリのURLは自分のものを送る。

登録フォームの項目は、授業ページの案内に従う。

### 15. 困ったときは、止まった場所を伝える

- ログインできない：サービス名と表示内容を教員に見せる。
- 何を開くか不明：授業ページへ戻り、指定リンクを開く。
- 送信できない：入力欄のエラーを確認。直せなければ相談する。

パスワードや認証コードは、他の人に見せない。

### 16. 準備が終わったら確認する

- [ ] 大学アカウントで授業ページを開ける。
- [ ] AIで短い質問を送れる。
- [ ] Privateのリポジトリと最初のcommitがある。
- [ ] 初回登録を送り、教員の閲覧権限を確認した。

### 17. 学生向け特典は、希望者が申請する

GitHub Educationの公式ページで、 対象条件と現在の特典を確認しよう。 審査の完了や有料プランの取得は、 この授業の参加条件ではありません。

特典の内容は変更される。授業では無料でできる手順も用意する。

## 使用機能に制限がある場合

有料契約は必要ありません。添付機能が使えなければ本文や小さな表を貼り付け、画像やグラフを生成できなければ文章・表で同じ確認を行います。AIの利用上限や障害で止まった場合は、既に得た出力の確認まで進め、制限があったことを記録してください。機能の利用可否は採点しません。

## 出典と権利

授業用架空資料は、その性質を変えずに使ってください。スライド中の操作図は実画面のスクリーンショットではありません。製品の操作名は2026年9月17日時点の公式資料を参照しています。詳しい出典はスライドのノートと[参考資料](../docs/slides_v1.1_references.md)にあります。
