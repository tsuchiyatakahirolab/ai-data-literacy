# 年度別のツール案内

確認日：2026年9月17日。機能、利用上限、学生特典、画面の配置は更新されるため、授業開始前に公式資料で確認します。

大学アカウントで使えるGeminiを基本環境として案内しますが、課題の条件を満たせれば他のAIを使って構いません。有料契約は不要です。添付機能が使えない場合の本文貼り付け、画像・グラフを作れない場合の表による提出を演習シートに用意しています。

学生特典は[GitHub Student Developer Packの公式ページ](https://education.github.com/pack)で、その時点の対象条件と内容を確認してください。特定の有料AIプランが無料で使えることは保証しません。特典の審査や取得は成績要件にしません。

- [ChatGPTの機能案内](https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview)
- [Geminiのファイル利用](https://support.google.com/gemini/answer/14903178)
- [GitHubの登録](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github)

2027年度以降も、学習目標や配布資料を全面的に作り直すのではなく、まずこのファイルと操作ガイドを更新します。ただし、授業で実際に使って分かった問題は、本体も修正してください。
