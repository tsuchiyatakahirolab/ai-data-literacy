## ファイルの使い方

授業ではPPTXをPowerPointで開いて使います。Google Driveなどで共有する場合も、PPTXのまま保管すれば編集元を保てます。別のスライド形式へ変換した場合は、字体と改行を改めて確認してください。

メイリオがない環境では代替フォントになるため、配布用PDFはメイリオの入った端末でPowerPointから書き出してください。字体の再配布やフォントファイルの同梱は行っていません。

フォームのスクリプトは別配布のV6をそのまま使います。この版ではフォームを変更していません。


[改訂した導入PDF](00_Course_Setup_v1.3.pdf)も閲覧できます。導入v1.3は途中参加とブラウザでの保存手順に対応します。

導入29枚と第3回21枚は2026-10-06の改訂です。他の14ファイルは同梱v1.1を維持しています。導入PDFはレビュー済みのスライド画像を配置した閲覧版で、検索・編集用テキストはPPTXにあります。PowerPointのネイティブ表示は未確認です。
