## ファイルの使い方

授業ではPPTXをPowerPointで開いて使います。Google Driveなどで共有する場合も、PPTXのまま保管すれば編集元を保てます。別のスライド形式へ変換した場合は、字体と改行を改めて確認してください。

メイリオがない環境では代替フォントになるため、配布用PDFはメイリオの入った端末でPowerPointから書き出してください。字体の再配布やフォントファイルの同梱は行っていません。

フォームのスクリプトは別配布のV6をそのまま使います。この版ではフォームを変更していません。


[改訂した導入PDF](00_Course_Setup_v1.4.pdf)も閲覧できます。導入v1.4は途中参加とブラウザでの保存手順に対応します。

導入37枚は2026-10-07のv1.4、第3回21枚は2026-10-06のv1.3です。他の14ファイルの本文は同梱v1.1を維持しています。導入PDFはレビュー済みのスライド画像を配置した閲覧版で、検索・編集用テキストはPPTXにあります。PowerPointのネイティブ表示は未確認です。

2026-10-07に16本・全242枚へ個人サイトのロゴと著者URLを追加しました。マスターを基本とし、暗色表紙は専用配置です。本文と既存の画像・ノートは維持しています。閲覧PDFはロゴをページ画像に含めています。出典表示を消せないという保証ではありません。[著者表示の記録](../docs/AUTHOR_BRANDING.md)。

2026-10-07の導入v1.4は、37枚の構成を保って初心者向けの操作説明を補足した版です。[1つずつ進める補助手順](../docs/setup_handson_step_by_step.md)と[改訂・確認記録](../docs/SETUP_V14_REVIEW.md)を用意しました。旧導入v1.3のPPTX/PDFは、既存URLの互換性と履歴のため残しています。現行一覧の16本には旧導入を数えていません。
