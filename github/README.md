# GitHub操作補習教材

GitHubのアカウント、自分の保存先、READMEの保存、教員への招待、commit URLによる提出を、ブラウザで一つずつ実習する教材です。はじめて使う学生と、一度設定したが手順を確かめたい学生が同じ資料を使えます。

1. [日本語の実習手順](../handouts/github_hands_on.md)を開き、1操作ずつ進めます。自分の保存先がすでにあれば、そのまま使います。
2. [スライド](../slides/GitHub_Hands_On_JA.pptx)／[ノートなしPDF](../slides/GitHub_Hands_On_JA.pdf)を横に開き、「できた目印」を自分の画面で確かめます。
3. [説明動画3本](../videos/github/README.md)は操作ごとに一時停止して使います。
4. 最後に[学生用チェックシート](../handouts/github_self_check.md)の01〜08を順に確認し、未完了の操作へ戻ります。

スライド・PDFは全18枚：表紙1枚＋操作15枚＋自己確認2枚。各操作の01〜15はページ番号とは異なります。PDFは表示用の画像です。文章のコピーには手順書かPPTXを使います。動画はダウンロードして標準のプレーヤーでも再生できます。

[教材・動画・空のひな形を一式ダウンロード](https://github.com/tsuchiyatakahirolab/ai-data-literacy/raw/refs/heads/main/downloads/GitHub_Hands_On.zip)／[English edition](../en/github/README.md)

教員は[進行メモ](../instructor/github_clinic.md)を使い、自分の授業のひな形、招待先username、初回登録・週次フォーム、練習する回を指定してください。授業固有の初回準備は既存の手順を使います。既存課題・提出・採点方針を使う補習です。学生の作業を何度も作り直したり、確認のための新しい提出を設けたりする必要はありません。
