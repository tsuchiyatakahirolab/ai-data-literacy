# AI・データリテラシーの提出用リポジトリ

このひな形は、課題の成果物と短いAI利用記録を保存するためのものです。授業ページの案内に従って、Use this templateから自分のPrivateリポジトリを作ります。既に作成した人は同じ保存先を使ってください。

## 最初に行うこと

初回準備の手順書に沿って、setupへ画像を1枚追加し、setup/README.mdへ記録を書きます。指定された教員を招待し、授業で指定されたアカウントで初回登録フォームを送ります。第2回以降から参加する人も同じ手順です。初回フォームへ送るのは自分のリポジトリURLです。

## 毎回の課題を提出する

今週の演習シートを読み、自分のweek01、week02などのフォルダを開きます。READMEへ成果物または成果物の説明、使用したAI、任せたこと、自分が確認したことを書きます。画像・PDF・CSVなどは同じフォルダへ別ファイルとして追加します。

必要なものを全部保存したら、最後のcommitを開き、そのURLを週次フォームへ送ります。ブラウザのCommit changesで保存します。追加のpush操作は不要です。最終課題はfinalを使います。

## 保存する情報を選ぶ

学籍番号・氏名・大学メールは初回登録フォームへ入力し、このREADMEや公開プロフィールには書きません。個人情報、秘密のキー、未許可の非公開資料を保存しないでください。AIとの会話全文や共有リンクも不要です。

学籍番号との対応は教員の非公開管理表で扱います。自分のusernameを学籍番号に変える必要はありません。授業ページの実リンクは教員の案内を使ってください。
