# Week 03: GitHubで混同しやすい用語

| 用語 | 意味 | 提出で必要か |
|---|---|---|
| username | GitHub URLに出る英数字の名前。例: `octocat`。 | 初回登録で必要。 |
| profile URL | 自分のGitHubプロフィール。例: `https://github.com/octocat`。 | 初回登録で必要。 |
| repository URL | 授業用成果物を置く場所。 | 初回登録で必要。 |
| commit URL | 特定時点の変更を示すURL。 | 毎回提出で必要。 |

repository URLだけでは提出時点が固定されません。毎回、commit URLを提出します。
