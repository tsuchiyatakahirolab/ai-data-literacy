## 授業内で行うこと

1. 最終課題の問いを1文で書き、対象と範囲を絞る。
2. 使う資料やデータを決め、AIに任せる作業と自分で確認する作業を分ける。
3. 成果物の形式、根拠ログ、GitHub提出までをチェックリストにする。

## 課題

最終課題の問いを1文で定め、使う資料、AIに任せる作業、自分で確認する項目、提出物を整理する。

## READMEに書くこと

```markdown
# Week 14: 総合演習の準備

## 成果物
今回作成した成果物を置く。画像、PDF、CSV、グラフを作った場合は同じフォルダに置いてリンクする。

## 使用したAI
使用したAIサービス名を書く。モデル名が分からない場合は「不明」でよい。

## 使用した機能
対話・説明、Web検索・調査、資料読解、画像理解、データ分析、画像生成・編集、音声、複数手順の実行などから、実際に使ったものを書く。

## AIに任せたこと
AIに依頼した作業を2～4文で書く。

## 自分で確認・修正したこと
AI出力のどこを確認し、何を直したかを3～5文で書く。

## 残った問題
確認できなかったこと、うまくいかなかったことがあれば書く。
```

## 提出方法

`week14/README.md` を更新し、必要なファイルを同じフォルダに置く。変更をcommitし、Google Formにcommit URLを提出する。

推奨 commit message: `week14-submission`

## 確認チェックリスト

- [ ] 課題で求められた成果物を置いた。
- [ ] AIに任せたことを書いた。
- [ ] 自分で確認・修正したことを書いた。
- [ ] 個人情報や非公開情報を含めていない。
- [ ] repository URLではなくcommit URLを提出した。
