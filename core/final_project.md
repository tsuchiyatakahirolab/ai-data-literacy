# Final Project: AIを使って根拠付きの成果物を完成させる

[English](../en/core/final_project.md)

## 演習手順

この回の操作手順、コピー用の依頼文、確認表は[演習シート](../handouts/final_project.md)にあります。スライドと同じ順番で進められます。

## 目的

最終課題では、授業で扱ったAI利用、資料読解、出典確認、数字・グラフの確認、GitHubによる作業記録を組み合わせる。評価するのはAIを使った量ではなく、問いに対して必要な根拠を集め、AIの出力を確認し、自分の判断で成果物を完成させた過程と結果である。

## 課題

自分で1つの問いを選び、AIを使って調査、資料読解、必要に応じたデータ確認、成果物作成を行う。テーマは授業内容、大学生活、国際関係、経済、社会、学習方法などから選んでよい。ただし、個人情報、非公開資料、実在の学生データは使わない。

## 提出物

1. `final/README.md` に、問い、使用したAI、AIに任せたこと、自分で確認・修正したこと、残った問題を書く。
2. 最終成果物を `final/` に置く。形式は、800～1,200字の説明文、1枚資料、表、グラフ、短いレポートなどから選ぶ。
3. 根拠ログを `final/evidence_log.md` またはREADME内の表として残す。
4. 最終課題を含むcommit URLをFinal Formで提出する。

## 根拠ログの形式

| 成果物で使った主張・数字 | 出典・資料 | 自分で確認した点 | 修正したこと |
|---|---|---|---|
|  |  |  |  |

## 評価基準

- 成果物 50%: 問いに答え、読者が理解できる形で完成している。
- 根拠確認と修正 25%: 出典、数字、日付、固有名詞、意味の変化を必要に応じて確認している。
- AI利用記録 15%: AIに任せたことと自分で判断・修正したことを説明できる。
- GitHub提出 10%: 指定フォルダに成果物を置き、commit URLで提出している。

## 提出前チェック

- [ ] 問いが1文で書かれている。
- [ ] AIに任せたことと自分で確認したことが分かる。
- [ ] 使用した主張、数字、日付、固有名詞について必要な確認を行った。
- [ ] 個人情報や非公開情報を含めていない。
- [ ] `final/README.md`、根拠ログ、成果物をcommitした。
- [ ] Final Formにcommit URLを提出した。
