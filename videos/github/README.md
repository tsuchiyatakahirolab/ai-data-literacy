# GitHub操作の短い解説動画 / Short GitHub walkthroughs

1本ごとに再生し、操作の場面で一時停止して、自分の画面を確認します。画面例と説明スライドに音声・字幕を付けた動画です。学生のPrivate保存先・大学フォームの操作を録画したものではありません。Windowsの合成音声を使用しています。

Watch one module, pause at each step, and check your own screen. These are narrated, captioned explanations using public-template and GitHub Docs screenshots, not recordings of a student's Private account or university form. The narration uses Windows synthetic voices.

MP4を直接開けないブラウザでは、ファイルをダウンロードして標準の動画プレーヤーで開きます。ZIP内では同じフォルダのMP4を開けます。字幕は動画へ焼き込んであるため、SRTの設定は不要です。If the browser downloads rather than plays the MP4, open it in your video player. The captions are burned in; no subtitle setup is required. The SRT files support later editing. Automatic subtitle timing may differ slightly from the narration.

教員は[30分補習の進行メモ](../../instructor/github_clinic.md)／[English teaching plan](../../en/docs/github_clinic.md)を使い、各操作で学生を待ってください。既存の課題・締切・フォームを使います。保存、招待、フォーム受付、教員による確認を分けます。

画像の出典：[新しい公開画面の台帳](../../assets/github-handson/SOURCES.json)、[GitHub Docsの既存画面例](../../assets/setup/screens/ATTRIBUTION.md)。教材の著者と[ライセンス](../../LICENSE.md)を保持してください。

最後に学生本人が[日本語の自己確認01〜08](../../handouts/github_self_check.md)／[English self-check 01–08](../../en/handouts/github_self_check.md)を順に開いて確認します。The covered deck adds two self-check pages after the same 15 actions shown in these videos.
