# Which repository is open?

## 1. Which repository is open?

Look at the name to the left of the slash at the top. It identifies the repository owner. Opening the instructor material does not create your own repository. If you already own ai-learning, continue there. Pause and check the owner.

## 2. Sign in to GitHub

GitHub is a separate account from your university page or Google account. Keep your existing account. New users sign up and follow the verification email. Open Profile and note the username in its address. Enter passwords and sign-in codes yourself. Pause to finish this step.

## 3. Create from the template

Open the course student template. Choose Use this template, then Create a new repository. A star or a browser bookmark does not create your repository. If the button is missing, check that you are signed in. Skip creation if you already have your own repository. Pause before continuing.

## 4. Owner, name, and visibility

Choose your own account as Owner, enter ai-learning, and select Private. Use Create repository from template, or the equivalent creation button shown. The image contains example values; do not copy github or hello. After creation, check your username and the Private label. Pause here.

## 5. Check your own repository

Open Code in your own ai-learning and find setup and the week folders. If they are missing, ask your instructor before recreating anything. Preserve existing work. The repository address is used for initial registration, which is separate from invitation and weekly submission. Pause and bookmark your repository.
