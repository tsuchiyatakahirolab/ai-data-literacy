# Open your README

## 6. Open your README

Open README.md in the week folder chosen by your instructor, in your own ai-learning. Read the teaching material in the instructor repository and write in your own file. Click the pencil. If it is missing, check ownership and sign-in. If you are asked to fork or propose changes, stop and ask for help.

## 7. Add a short record

Keep the headings and existing work. Add one sentence about a check you actually performed, under your own checking record. Do not claim a check you did not perform. Text in the editor is not yet saved. Pause and write your sentence in your own words.

## 8. Check the Preview

Choose Preview and check how the text appears to a reader. Confirm your sentence and headings are readable. Return to Edit if you need a correction. Preview checks the appearance; it does not save the change. Pause and inspect it.

## 9. Save with Commit changes

Click Commit changes to open the save dialog. Enter a brief message, such as Add checking record. In your own course repository, choose Commit directly to the main branch and confirm with the final Commit changes button. Reopen README to check that your sentence remains. Browser saving needs no separate push. Pause and reopen the file.
