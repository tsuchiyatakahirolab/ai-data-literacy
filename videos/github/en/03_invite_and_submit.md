# Invite your instructor

## 10. Invite your instructor

Sending a Private repository URL alone does not give your instructor access. In your repository Settings, choose Collaborators and Add people. Check the full course instructor username, select the match, and confirm the final Add button. Pending means your invitation was sent, while instructor access still awaits acceptance. Do not repeat an accepted invitation. Pause to check the list.

## 11. Find the commit history

Save all required files, then return to Code at the root of your repository. At the upper right of the file list, click the clock icon and the number beside Commits. A narrow screen may show only the icon. This is not the global menu or Insights. Pause and open your own history.

## 12. Open the final commit

Click the newest message after all your required files were saved. The address contains slash commit slash followed by the commit identifier. Check the author, time, and save message. The Copy SHA button copies only the identifier, not the full submission URL. Pause and open the commit page.

## 13. Check the submitted version

A commit page mainly shows changes. Use Browse files at the upper right to inspect the complete file list at that version. Check the required README and artifacts in the chosen week folder. If a file is missing, add and save it, then use the newer final commit. Return to the commit page to copy its address.

## 14. Submit through the course form

Return to the checked commit page. On Windows, use Control L to select the address bar and Control C to copy the full URL. Open the weekly form from your course page, check the account, week, and URL, then submit. Check the form confirmation. Saving on GitHub alone has not submitted the form.

## 15. Check each completion state

Check four things separately. Do you own a Private repository? Can you reopen the saved text? Is the instructor invitation listed? Did the form confirm receipt? The Verified badge on a commit is not instructor review or submission confirmation. Tell your instructor which check stopped you. These checks describe your operation, not your grade.
