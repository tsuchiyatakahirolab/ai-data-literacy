# いま開いている場所

## 1. いま開いている場所

最初に、画面上部のスラッシュの左側を見ます。そこは保存先の所有者です。教員の教材を開いているだけでは、自分の保存先はできていません。自分のユーザーネームと、エーアイ・ラーニングという名前の保存先がすでにある人は、それを使って続けます。ここで動画を一時停止して、所有者を確かめてください。

## 2. GitHubのログイン

ギットハブは、大学の授業ページやグーグルとは別のアカウントです。すでにアカウントがある人は作り直しません。初めての人はサインアップし、確認メールの案内を進めます。ログインしたらプロフィールを開き、アドレスにある自分のユーザーネームを控えます。パスワードや確認コードは本人だけが入力します。ここで一時停止します。

## 3. ひな形から作成する

授業の学生用ひな形を開きます。ユーズ・ディス・テンプレートを押し、クリエイト・ア・ニュー・リポジトリーを選びます。スターを付けることや、ページをお気に入りにすることでは、自分の保存先はできません。ボタンが見えなければ、ギットハブへのログインを確認します。作成済みの人は、同じものを増やさずに自分の保存先へ戻ります。

## 4. 所有者・名前・公開範囲

作成画面でオーナーを自分のアカウントにします。名前はエーアイ、ハイフン、ラーニングです。プライベートを選んで、クリエイト・リポジトリー・フロム・テンプレートで作成します。画像のギットハブやハローは公式文書の例なので、そのまま入力しません。作成後に自分のユーザーネームとプライベートの表示を確認してください。

## 5. 保存先ができた確認

自分の保存先でコードを開き、セットアップとウィークのフォルダがあるか確認します。フォルダがない場合は、作り直す前に教員へ画面を見せます。すでに書いた課題がある保存先は消しません。初回登録にはこの保存先のアドレスを使います。これは教員への招待や週次の提出とは別の操作です。ここで一時停止して、自分の保存先をお気に入りに入れてください。
