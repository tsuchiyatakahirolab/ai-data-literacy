# READMEを開く場所

## 6. READMEを開く場所

ここから保存の練習です。教員が指定したウィークのフォルダで、リードミー、ドット、エムディーを開きます。読む教材と、書くファイルを区別します。右上の鉛筆を押してください。鉛筆が見えない場合は、自分の保存先か、ログインしているかを確認します。フォークや変更提案の表示が出たら、保存せず教員に相談します。

## 7. 短い記録の追記

すでに書いた課題や見出しを残したまま、自分で確認したことの欄に、実際に行った操作を一行追記します。たとえば、ギットハブでファイルを開き直して確認しました、という内容です。まだ確認していないことは書きません。入力欄に文章があるだけでは、保存は終わっていません。ここで一時停止して、自分の言葉で一行を書いてください。

## 8. Previewで見え方を確認

プレビューを押して、読み手にどう見えるかを確認します。自分の追記と見出しが読めるか見ます。直す必要があればエディットへ戻ります。プレビューは表示の確認で、保存ではありません。ここで一時停止して、書いた文章が見えるか確認してください。

## 9. Commit changesで保存

コミット・チェンジズを押すと、保存の確認画面が開きます。説明欄へ、たとえば操作記録を追記、と入力します。この授業の自分用保存先では、コミット・ダイレクトリー・トゥ・ザ・メイン・ブランチを選び、最後のコミット・チェンジズで確定します。画面が戻ったらリードミーを開き直します。文章が残っていれば保存済みです。別のプッシュ操作は要りません。ここで一時停止して開き直してください。
