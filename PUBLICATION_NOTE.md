# Publication Note

This repository is an open educational resource for AI and data literacy exercises. It is designed for university students with little or no prior experience using generative AI, GitHub, or data analysis.

The public repository does not contain student records, Google Form URLs, dashboard links, institutional account data, or real student datasets. Course operators should manage those materials in a private operations environment.

Sample data and exercise materials in `assets/` are synthetic or created for teaching purposes unless otherwise stated.
